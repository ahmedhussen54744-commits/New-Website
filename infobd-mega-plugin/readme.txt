Mega plugin for Infobd.online — 80+ features mixing News portal + Gaming + eCommerce, with security hardening, copyright protection, and a beautiful 3D admin dashboard.

== Description ==
Infobd Mega Plugin is the all-in-one companion plugin for the Infobd 3D theme. It packs 80+ toggleable features:

* 16 security hardening options (XML-RPC off, login attempt limiter, security headers, bad bot blocker, REST gating, etc.)
* 10 copyright protection layers (right-click, copy, drag, view-source, devtools shortcuts, watermark, etc.)
* News portal features (breaking ticker, trending, view counter, reading progress)
* Gaming Zone with custom post type, score, system requirements
* Lightweight Shop / eCommerce CPT (price, stock, wishlist, buy URL)
* Public features: dark mode, font size, reading mode, like, bookmark, image zoom, TOC, live search
* Built-in SEO (meta description, OG, Twitter Cards, JSON-LD, canonical, breadcrumbs)
* Performance helpers (disable emoji/embeds, DNS prefetch, version stripping)
* Ad slots (header + in-post)
* Post link / slug editor with custom permalink override
* Admin dashboard with live stats, quick actions, and bulk feature toggle

== Installation ==
1. Upload the plugin zip via Plugins → Add New → Upload Plugin.
2. Activate it.
3. Go to "Infobd Mega" in your admin sidebar to configure.
